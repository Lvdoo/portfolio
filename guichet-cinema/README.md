# 🎟 LL PICTURES — THE BOX OFFICE · 3D Cinema Portfolio

**Ludo La Bête**'s interactive portfolio, reinvented as a **3D cinema box office**: six tickets laid on a counter (Three.js / WebGL), each one a project. The tickets wait in a **fixed flat pile** on the counter; **just scroll (no click needed) or click the pile to pick one up**, **spin it** with the mouse to read the back, then **STAMP it**: the full "film" card opens.

The site fits on **a single screen**. **Scrolling anywhere** picks the top ticket up and then **cycles the tickets**; a ticket in hand is cycled the same way. **On a phone: swipe up / down** (up = next ticket, down = previous) anywhere on the scene. The page itself never scrolls. The classic sections (**About / Contact**) open as **full-screen panels** from the menu.

> ✨ **No build, no server.** Just open `index.html` (double-click).

## ▶ Run it

1. Double-click `index.html` (works over `file://`).
2. An internet connection helps on first load: Google fonts (Anton / Archivo / Playfair Display) + Three.js r160 from jsdelivr (cached afterwards).

**At the counter:**
- **Loading** → a **`3 · 2 · 1` countdown** on black (no Play logo, no click needed). Each digit fades/scales in; the counter **stops on " 1 "** and simply waits for the real resources (assets, fonts, WebGL scene). Nothing artificial is added when everything is ready early; a **hard timeout** (12 s) guarantees the scene is revealed even if a CDN or WebGL hiccups, so you are never left stuck on the countdown.
- **The bottom black bar** (`#ticketBar`) carries **only the project list** — the six titles, spread horizontally and **vertically centred**. On a desktop hover a name **grows slightly** (`scale`); on touch the active state does the same job. If the names don't fit (narrow phone), the list **scrolls horizontally inside the bar** — a horizontal swipe on the list **never** triggers the vertical ticket pick-up. **Where the list lives is decided by MEASUREMENT, not by a media query**: the width the six titles really need is compared with the width the black bar really offers. If they fit on **one line**, the list stays in the bar (desktop, tablet, phone in landscape). If they don't, the list **moves onto the booth's facade** — the front face of the wooden counter, projected to screen pixels exactly like the bell's arrow — where it is laid out in **several rows**, bigger and more readable, inside a small plate screwed on the wood, with the safe-area margins respected and never overlapping the in-hand ticket, the STAMP button or the black band. If the facade is out of frame (a small window), the list **stays in the bar and scrolls horizontally** — the fallback, never a lost list. **Above** the black bar (not inside it) sit two separate fixed elements: the **`SCROLL TO CHOOSE A TICKET`** state label, **centred horizontally** (`.stamp-meta`, at rest it reads `SCROLL TO CHOOSE A TICKET` in gold, and turns into the in-hand project's name once a ticket is picked up), and the **STAMP button**, pinned to the **right** — which appears **only when a ticket is actually in hand** (`body.hand`), since it is the ticket's action, not a permanent marker. The **hint only shows when the booth is OPEN** (`body.booth-closed` hides it): behind closed curtains there is nothing to pick, so the bell is the only cue. The bar and the hint are shown **as soon as boot finishes, even if WebGL is unavailable** (`boot()` guarantees it in a `finally`), so the projects are never lost behind a failed 3D scene. **Layering**: bar, hint and STAMP all sit at `z-index: 353`, i.e. **above** the black letterbox bars (`.cine-bar`, `352`) and the film grain (`#grain`, `351`) — this matters because `#ticketBar` occupies **exactly the same place** as `.cine-bar--bottom` (both `bottom:0`, same height). When the list was moved *into* the bottom black bar, the bar ended up **behind** the letterbox, which painted over the content: it was in the DOM, `opacity:1`, correct size — and invisible. The bar is also **visible by default in CSS** (it no longer depends on a JS-added `.show` class); only `body[data-loading="true"]` fades it out during the countdown. Finally, the STAMP button's show/hide is driven by **`visibility` toggled instantly** (only `opacity`/`transform` are transitioned): `visibility` is a *discrete* property and, when transitioned, can stay stuck on `hidden` if the transition is interrupted — so it is flipped without any transition.
- **Click a project name** → **its "film" card opens directly** (`openProjectDirect()`): no intermediate step through the ticket in hand. Curtains are opened if shut, any open panel is closed, the ticket is marked stamped for a coherent state, and the card shows **that** project — the **first, middle or last** alike. This is the single shared entry point, so no opening logic is duplicated.
- **Start** → the site **boots with the curtains shut** (`boothsClosed = true`, `curtainT = 1`): the ticket window is covered by the red velvet, **every light is out except the brass bell**, which glows and **pulses** under a small **gold arrow floating above it, bobbing up and down** (`#bellHint` — a real `<button>` holding only the `.bh-arrow` (no text), **posed above the bell's summit** by `placeBellHint()`, which projects that summit to screen pixels and re-places the arrow **every frame** — so it follows the bell and the camera parallax on every format; clicking or keyboard-activating it rings the bell, so the booth can also be opened from the keyboard). Nothing else is selectable yet — you ring to open.
- **Click the brass bell** (on the counter, left of the pile) → **opens / closes the red velvet curtains**. Open = the lights come back, no ticket in hand, the pile of tickets to stamp sits **flat and fixed**, **centred** on the counter, lit by a **strong pulsing halo**. Closed = the booth is shut: the curtains draw across the ticket window, **every light goes out except the bell**, the tickets can **no longer be selected** (neither by scroll nor by click), and the bobbing arrow above the bell comes back — click the bell again to reopen.
- **Move the mouse** → a **little projector follows the cursor**: a soft **light shaft** drops from above onto the exact spot you're pointing at, a real `SpotLight` **lights the surface** and a warm **pool of light** lies flat on it (`placeCursorBeam()`). Point at a **ticket** and the projector targets *the ticket itself*: the pool sits on its paper and the ticket **lights up** — its panels are unlit (`MeshBasicMaterial`), so their colour is raised to fake the spotlight. It fades out with the rest of the lights when the booth closes, off the 3D scene (panels / film card / scrolled away), and on touch screens it only lights up **while you press**.
- **Scroll anywhere** (or click the pile) → the top ticket **rises to the centre** (large, readable; scaled to fit, never cropped); keep scrolling to browse the tickets. **On a phone, swipe up / down** to browse (see below). The in-hand ticket also **lifts a little higher** (`heroRest()`) so it visually detaches from the counter: the lift is **proportional to the screen size** — strong on a desktop, discreet on a phone where space is tight — and it always stays entirely inside the frame.
- **Hold left click + drag** → rotate (front / back).
- **Wheel / trackpad, or `↑` `↓` `←` `→`** → cycle the ticket in hand (**down / `↑` / `→` = next**, **up / `↓` / `←` = previous**); **with no ticket in hand they pick the top ticket up** (they replace the click). The page never scrolls.
- **On a phone: swipe up / down** → the same navigation, in the same direction (up = next, down = previous), **anywhere on the scene** (nothing to aim at). A swipe is never taken for a click, a ticket in hand **stays in hand** while you browse, and the incoming ticket **enters from the side you pushed** (out of the pile going forward, down from above going back).
- **Click outside the ticket** → put it back on the pile.
- **STAMP** → the ticket straightens up, takes the red **"ADMITTED"** stamp, the "film" card opens, then the ticket is **pinned up inside the booth** and you're back to the pile.
- **On a pinned ticket** → hover to lift it, click to **reopen its "film" card** (stamped tickets stay visible and reachable at all times).
- **The "film" card shares the ticket's art direction**: aged ivory paper, sepia ink, Playfair letterpress title, gold photo frame and dashed perforation rules, with the **accent band of that project** down the left (faded band on the right) — the card reads as the same printing as the ticket.
- **The card's top bar (stamp + ROOM / SCREENING) stays fixed** while the poster scrolls under it. The poster head is deliberately **light**: the **kicker** (`DOMAIN • YEAR`, e.g. `AI - Computer Vision • 2024 - 2025`), the **giant title** and the **tagline** — the domain/year line used to be repeated under the title, it has been removed so the poster breathes. The card body shows **real project information only** (domain, year, role, tools) — the fictional cinema metadata (room, genre, runtime, showtime) lives **only on the tickets themselves**, never on the posters. Close the card by **clicking outside** it or with `Esc` (or browse with `←` / `→`).
- **Menu (About · Contact)** → opens the section as a **full-screen sheet printed like a ticket** (cream paper, sepia ink, gold accents, accent band down the left, fixed top bar with stamp + ROOM); `Esc` (or the header's **BOX OFFICE** link) closes it.
- `Esc` → close the panel, otherwise the film card, otherwise put the ticket back down on the pile.

## ✎ Customise it (2 minutes)

Everything is set at the top of **`app.js`**:

```js
const CONFIG = {
  name: "Ludo La Bête",
  email: "LUDO.CREATIVE@EMAIL.COM",   // ← your real email
  github: "https://github.com/Lvdoo",
  sound: true,                        // default sound (♪ button, top right)
};
```

The 6 projects (title, year, domain, role, genre, room, runtime, tools, tagline, blurb, sections, links) live in `const PROJECTS = [...]` just below.

**Your CV:** drop it in `assets/cv/` named exactly **`CV-Ludovic-LI.pdf`** — the **ABOUT** panel's "* CV - PDF" button links to `assets/cv/CV-Ludovic-LI.pdf`. (Change the `href` of that link in `index.html` if you rename the file.)

> `accent` = the project colour (ticket stripe, title, card). Pick it **dark/saturated** enough to stay legible on the cream paper.

## 🛠 Technical details

- **Three.js r160** (UMD build via CDN) — real WebGL, textures **drawn on canvas**: vintage **horizontal tickets with a tear-off stub** (vertical perforation, torn edges, punch notches, Playfair serif type, typed mentions, rosette, series + barcode, PRIX/PRICE box), aged cream paper, "ADMITTED" stamp.
- **Vintage box office** (all UI text in English): dark waxed panelling, worn brass, a **shallow wooden counter** (you're leaning on it), a **giant ticket window with no bars** that **fills the entire screen** (the booth stays fully visible), a **red/cream striped scalloped awning spanning the WHOLE width**, a "marquee" bulb garland along its lower edge, a **"BOX OFFICE" plaque** and **English cinema posters** (both **flat on the wall** — no backing board and no added frame; the thin gold border is part of the artwork), a **framed PRICES board standing on the counter** (fully visible, never cropped), a brass counter bell, and a chequered floor. The **plaque and posters sit on the SAME PLANE as the stamped-tickets board** (the booth's back wall), so they read as mounted and never drift relative to it; the **PRICES board rests on the counter** and the **red velvet curtains** stay **on the sides**, pinned to the screen edges — until you **click the brass bell**, which **draws them shut across the window** (`layoutCurtains()`, animated through `curtainT`).
- **You ARE at the counter**: the camera sits **right at the window** (very short pull-back on desktop) and tilts slightly down; the wall is at `z = 0` and the **ticket window fills the whole screen** — it *is* the screen. The **BOX OFFICE plaque** and the **posters** are **fixed on the booth's back wall, co-planar with the stamped-tickets board** (left/right of it and just above it), the **PRICES board** stands **on the counter**; only the **curtains** follow the screen edges (`placeFacade()` / `layoutCurtains()`), the **brass bell** is kept visible (`placeBell()`) and the **wall clock** (`placeClock()`) slides to stay clear of the plaque whatever the width.
- **Customer POV — you see the booth**: the ticket window is a **real opening** in the wall; behind it the **booth interior** is kept deliberately **bare and lit** — a **wall clock set to the viewer's local time** (hung to the **left of the BOX OFFICE plaque**), on the same back wall the **BOX OFFICE plaque** and the two **posters** are mounted on (flat, co-planar with the stamped-tickets board), plus **two award statuettes resting on the counter, just to the RIGHT of the red poster** (`placeCesar()`), at **true museum scale** (1 world unit = 1 metre, **no scaling factor**): a **CÉSAR** (the French trophy by César Baldaccini — 29 cm, modelled as the **compression** of furniture ornaments: a slender, twisted, faceted gilded-bronze mass whose section leans and rotates as it rises, with wrought folds, ornament bosses and **real ornament fragments left protruding** — a bevelled **ExtrudeGeometry rosette**, a couched moulding ring, a frame chip — a **hollow craggy top**, and a patina carried by **vertex colours** (bright gold on the ridges, warm brown in the folds); it stands on a **black 8 × 8 cm plinth** carrying a **flat brass plate engraved** with its motto `FROM CODE TO REALITY` (no personal name — the name lives in the Contact section only) — `makeCesarStatue()`) and, right beside it, an **OSCAR** (the Academy Award of Merit by Cedric Gibbons / George Stanley — 34.3 cm: the Art Deco **faceless knight** with a smooth, streamlined body (capsule limbs, lathe torso and egg head, **shoulders brought down, arms folded in front**), holding a **crusader's sword point-down**, the blade running between the legs down to the **five-spoke film-reel** it stands on, atop a **black lacquered 13.3 cm pedestal** (clearcoat) carrying a **curved brass plate engraved** with its motto `CREATIVE TECHNOLOGIST` — `makeOscarStatue()`); **click a statuette to take it in hand** — it rises in front of you, **engraved plate facing the glass**, replacing the former cashier silhouette (the middle table, till, decorative tickets, stamp and desk lamp have been removed). Both are **real PBR metal** (`MeshPhysicalMaterial`, roughness maps, gold/bronze palette, the plate's text used as a `bumpMap` so the engraving really catches the light), lit by the shared PMREM environment (`getAwardEnv()`), and a **dedicated shadowless spotlight** (`awardSpot`) softly reveals the volumes of whichever trophy you hold. A faint glass reflection keeps the pane readable.
- **Stamped tickets = pinned to the board**: a brass frame made of 4 bars laid **in front of** the ticket (so it always frames it, never hidden behind), + a pin; laid out in a **3 × 2 grid on the display board inside the booth** (seen through the window). The frame + pin fade in only once the ticket has reached the board; hover = lift, click = reopen the card.
- **Un-stamped tickets**: nothing is in hand at rest — the tickets wait in a **fixed flat pile, centred on the counter** (highlighted by a **strong, pulsing warm halo**) that **never reshuffles** as you pick, cycle or stamp. **Scroll or click the pile** to bring the top ticket into your hand (scaled to fit the viewport, never cropped, so it stays readable); click outside it to lay it back down. The remaining count is **no longer displayed** (the hint reads `ALL STAMPED` once every ticket is stamped).
- **Closing time (the bell)**: clicking the **brass bell** (`toggleCurtains()`) closes the booth — the curtains sweep shut, **every light is damped down except a dedicated spot + glow on the bell** (`applyCurtainLighting()`), the pile halo goes out, and ticket interaction is **fully locked** (wheel, click, drag, swipe and arrow keys are all ignored); any ticket in hand is laid back down. Click the bell again to reopen.
- **Cursor projector** (`placeCursorBeam()`): the pointer ray is first tested against **every ticket** (`ticketMeshes`); a hit targets **that ticket** (its paper, its own face normal). Otherwise the ray is intersected with the **counter** (`y = 0`, when the hit lands between `z ≈ .15` and `2.05`) or, failing that, the **back wall** (`z = -2.19`). A `SpotLight` (angle `.19`, penumbra `.9`, warm `#ffe4bc`) hangs `(+0, +2.2, +1.05)` above the point — always clamped to stay **in front of the camera** — and the **visible beam** is a single **camera-facing quad** (a soft canvas cone texture, no hard silhouette edges) spanned from the source to the hit; the **pool of light** is a `PlaneGeometry` laid **on the surface plane** (i.e. on the ticket). Since tickets are unlit, the target ticket's **material colour is raised to `1 + .22 * lit`** (`lit` lerping back to `0`), which is what makes it read as lit. Everything is scaled by a single `cursorFade` ramped by `(1 - curtainT)` and gated by `cursorOn && heroActive && !openPanel && !detailOpen && !stampingLock`; touch pointers (`trackCursor()`) only hold it while pressed.
- **TeruBot video** redrawn ~15 fps onto the ticket while it's hovered/focused (one video at a time, for performance).
- **100% synthesised sound** (WebAudio): hover, pick-up, paper, stamp, open, bell — mute button `SOUND ON`.
- **Cinema art direction**: animated 35 mm grain, letterbox, 24 fps timecode, projector beam, dust.
- **"Film" card**: a **fixed top bar** (stamp + ROOM / SCREENING) over a **scrolling poster**; room, genre, runtime, synopsis, sections, 1–2 de-duplicated media, keyboard navigation (`←` / `→` / `Esc`, click outside to close).
- **Single page**: the section panels never scroll the page itself; **the wheel picks a ticket up / cycles the tickets, anywhere on the screen** (the page never scrolls). About and Contact are **full-screen panels** opened from the menu (`Esc`, or the header's **BOX OFFICE** link, to leave), each scrolling internally if needed.
- **Responsive**: on **desktop** the camera is glued to the counter (you're at the window); **tablet** and **mobile portrait** pull back to fit the width. The **row of stamped tickets** (3 × 2 grid on the board) and the **stack of tickets to stamp** (now **centred**) recompute against the visible width on every resize; the **curtains** are pinned to the screen edges (and, when closed, are sized to cover the whole viewport), the **brass bell** is kept at a constant on-screen position (`placeBell()`), and the **arrow above it** stays glued to the bell's summit on every format (`placeBellHint()`, re-placed every frame), and the **BOX OFFICE plaque** stays fixed on the booth's back wall (co-planar with the stamped-tickets board). The objects that would end up **sliced by the screen edge** on a narrow window are treated one by one: the **wall clock** (`placeClock()`) and the **two posters** (`placePosters()`) are either **entirely in frame** (shrunk a little if needed) or **entirely out of it** — never cut in half; the **PRICES board** stands on the counter and **slides towards the centre while shrinking** so that it too stays **entirely** visible (`placeTarifs()`). The **ticket window is wider than any screen** (including 21:9), so no bare wall ever shows on the sides. Click = rotate on mobile, stamp = button. The panels follow (`padding` and counter height via `--bar`). Every measurement goes through **`viewSize()` / `viewAspect()`** (the **real canvas box**, *not* `window.innerWidth/innerHeight`, which disagree with it on iOS while the URL bar moves), and the film card is inset in **`dvh`** so it always fits the visible screen (with `vh` as fallback, plus the safe-area insets).
- **Phone framing (portrait) is its own camera, not a push-back**: on a **portrait phone** the vertical **field of view opens up** (`frameFov()`: 46° on wide screens → up to 64° at aspect ≈ .46) and the pull-back distance is **derived from it** (`frameDistance()`), so the **outer edge of the English posters** stays inside the frame (`FRAME_HALF_W`) instead of being pushed out of it. Portrait therefore shows the **whole wall** — both posters (now **fully visible**: they used to be pushed off-frame), the **BOX OFFICE plaque clear of the awning**, the wall clock, the PRICES board and the two statuettes — while the **counter stays in frame down to its skirting** (`cz` clamped to `[5.0, 12.0] m`, `.85 → .46` ramp). Side effect: with such a wide field of view, the **open** curtains only leave a **few-pixel velvet edge** down the sides (the posters take the whole width) — but the **closed** curtains still cover the screen. **Rotating the phone** recomputes everything at once (`orientationchange` + `resize` + `visualViewport`).
- **Touch = one finger, one gesture, and one ticket per gesture** (`gestureId` / `endGesture()`): navigation is a **vertical swipe** — **up = next ticket, down = previous** — the natural direction of the pile, and the direction the **wheel / trackpad** already sends (`deltaY`), so finger and trackpad agree. `swipeDir()` is a **pure function** (no state), so the rule is testable on its own; it demands three things so a swipe is never confused with anything else: a **minimum travel** (`max(44 px, 14 % of the screen height)`, capped at 120 px) — which a **tap** can never reach, and which keeps the **tilt of the ticket in hand** (it saturates around 50 px) a rotation; a **clear vertical dominance** (`|dy| ≥ 1.15 |dx|`); and a **firm gesture** — quick (`≥ .30 px/ms`) *or* long (`≥ 1.8 × the threshold`), and inside 1.4 s. Everything else — opening a card, ringing the bell, laying a ticket or a statuette back — is **deferred to `pointerup`** (`pendingTap`) and only fires when *no* swipe happened, so **a swipe never leaves a stray click behind and never lays the ticket in hand back down** (it straightens up instead). One gesture changes **one** ticket (the action fires at release, once), the **first / last** ticket wrap without error, and the **first swipe with nothing in hand** brings up the pile's top ticket. `pointercancel` and `blur` close the gesture cleanly: a finger leaving the canvas, the URL bar unfolding or a phone call can no longer leave the app **stuck**. `touch-action: none` is **scoped to `#stage`** — the canvas, which *is* the navigation zone — while the film card (`.detail-scroll`) and the panels keep their own scrolling and `overscroll-behavior: contain`; the page itself never scrolls (`overflow: hidden` + `overscroll-behavior: none`). There is **no hover on touch** (hover stays mouse/pen only), and the compatibility "mouse" events the browser fires right after a tap are ignored (`isGhostMouse`), so nothing plays twice.
- **The ticket in hand is centred in the FREE zone, not in the canvas**: the interface takes a real part of the screen (the two black bars, the safe-area notches, the `SCROLL TO CHOOSE A TICKET` hint, the `STAMP` button), so the **free** zone is **measured** — `measureHeroZone()` queries the bars and the hint and reads the notches from `env(safe-area-inset-*)` — and the ticket is **centred in it**, not at the mathematical centre of the canvas. The **camera is left alone**: the scene keeps its framing, its proportions and its perspective; the ticket stays a real 3D object, **repositioned in world space** so that it lands exactly where it should be seen (`worldAtScreen()` / `screenAtWorld()` invert the projection through the camera's frame, down to the pixel). The recentring is **total** on a **narrow screen** (phone in portrait, tablet) and when the free zone is **low** (phone in landscape); on a **big screen** the original framing is kept — `heroCenterGain()` ramps smoothly from 0 to 1, so no format ever "jumps". The ticket also **fits** the free zone (`fitW` / `fitH`): it can never be cropped by a screen edge, and the rise is counted in the room that is left. The small **rise** that detaches the ticket from the counter is kept — it now simply lifts it a touch above the centre of the free zone. `window.__hero()` reports the ticket's on-screen box, the free zone and the gain, format by format.
- **Objects stay tappable from far away**: at portrait distance the flat pile is only ~13 px tall and a statuette a few px wide, which is why a **miss-only touch slop** (`TAP_RADIUS_PX = 34 px` around the object's centre — `nearObject()` / `nearAward()` / `nearBell()`) takes over **only when the exact raycast hits nothing**. The exact ray always wins, so on desktop (large objects) the slop never fires.
- **Every frame does one thing** (`startLoop()`): the loop is split into small named passes — `updateCamera()`, `updateDust()`, `updateCurtains()`, `placeCursorBeam()`, `updatePileGlow()`, `updateAwards()`, `updateTickets()` — then the render. Nothing is computed while the tab is **hidden**, the 35 mm grain is drawn into a **capped-size bitmap** (≈120 k px) stretched by the CSS instead of a half-screen one, and **resize events are coalesced** into a single recalculation per frame, with `devicePixelRatio` re-checked every time (`onResize()`).
- **Accessibility**: real semantics (`<h1>`, `<nav aria-label>`, `<dl>` pairs, `<button>` everywhere), the mobile menu keeps `aria-hidden` / `aria-expanded` in sync and hands focus back (`setMobileMenu()`), the hint above the bell is a **real button** (so the booth can be opened with the keyboard, with a generous touch target), focus moves into the film card when it opens, `prefers-reduced-motion` is honoured, and nothing is hover-only.
- **Fallback**: without WebGL, a fallback list (in the message) opens the 6 cards directly.
